INSTRUCOES

1. Extraia esta pasta.
2. Abra a pasta Codigo_5 no Visual Studio Code.
3. Abra o terminal dentro da pasta.
4. Execute: npm install
5. Execute: npx expo start
6. Leia o QR Code com o Expo Go no celular.

O projeto contem:
- Lista de contatos usando FlatList.
- renderItem e keyExtractor.
- Separador entre os contatos.
- Mensagem quando a agenda estiver vazia.
- Botao para limpar a agenda.
- Pull-to-refresh: arraste a lista para baixo para restaurar os contatos.
- Rolagem infinita: chegue ao final da lista para adicionar mais tres contatos.

Observacao: e necessario ter Node.js instalado e o Expo Go no celular.
